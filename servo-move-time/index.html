서보 이동시간

정지에서 정지까지의 이론 이동시간이며 실측값이 아닙니다. PLC에 쓰지 않습니다.

가감속 시간은 0과 최고속도 사이를 기준으로 합니다. 낮은 지령 속도나 짧은 이동에서는 실제 구간 시간이 짧아집니다.

이론 이동시간입니다. 장비 안전이나 서보 선정을 보장하지 않습니다.

PLCManJP 홈엔지니어 도구 목록으로

서보 이동시간 도움말

단일 축의 정지에서 정지까지 이론 이동시간과 가감속 프로파일을 계산합니다.

사용 방법

  1. 시작 위치, 목표 위치, 지령 속도, 최고속도, 공유 속도 단위와 가감속 시간(ms)을 입력합니다.
  2. 가감속 시간은 0과 최고속도 사이를 기준으로 합니다. 지령 속도가 낮거나 이동 거리가 짧으면 실제 구간 시간이 짧아집니다.
  3. 재생은 1배속 시뮬레이션입니다. 일시정지는 가상 시간을 멈추며 실제 감속이 아닙니다.
  4. 입력을 바꾸면 재생이 멈추고 시작 위치에서 다시 계산합니다. PLC에는 쓰지 않습니다.

참고

예: 20 mm에서 160 mm, 지령 속도와 최고속도 40 mm/sec, 가감속 시간 500 ms는 총 4.0초입니다.
